Estás usando la versión publicada en GitHub Pages: los datos se actualizan por un GitHub Action programado (no hay un servidor corriendo en vivo).

Pega el texto de una convocatoria puntual (funciona sin conexión a ningún servidor, el análisis corre en tu navegador). También puedes intentar con una URL, pero muchos sitios bloquean la descarga automática desde el navegador por seguridad (CORS); si falla, copia y pega el texto de la página.

Configuración de GitHub (necesaria para agregar/editar entidades y disparar "Actualizar ahora")

El banco de entidades vive en docs/data/entities.json dentro de este repositorio. Para editarlo desde aquí necesitas un personal access token de GitHub con permiso de escritura sobre este repo (recomendado: token de tipo "fine-grained", limitado a este repositorio, con permisos Contents: Read/write y Actions: Read/write). El token se guarda solo en este navegador (localStorage) y únicamente se usa para llamar a la API de GitHub.

Agregar entidad financiadora

Solo se necesita la URL del listado de convocatorias de la entidad: el sistema intentará detectar automáticamente los ítems la próxima vez que corra el scraping. Si conoces la estructura HTML del sitio, puedes afinar el resultado con selectores CSS opcionales (avanzado).
