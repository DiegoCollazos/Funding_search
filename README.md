# Funding Search

🔗 **Accede a la plataforma:** https://diegocollazos.github.io/Funding_search/

## Descripción

Funding Search es una herramienta web para identificar y monitorear
convocatorias de financiación (investigación, cooperación, innovación)
nacionales e internacionales. Permite:

- Identificar si una convocatoria es **nacional o internacional**.
- Buscar convocatorias por **palabras clave**, **línea temática** u **ODS**
  (Objetivos de Desarrollo Sostenible).
- Administrar el **banco de entidades financiadoras** (agregar la URL de una
  entidad y programar su scraping automático, sin escribir código).
- Ver, para cada convocatoria vigente, su **título**, **objetivo**, **fecha
  de cierre**, **monto a financiar** y si es viable que una **universidad
  pública** participe como ejecutora o aliada.

Los datos se actualizan automáticamente todos los días mediante un proceso
programado que revisa las páginas de las entidades registradas.

## Cómo usarlo

1. Entra al enlace de arriba.
2. **Buscar convocatorias**: filtra por palabra clave, línea temática, ODS,
   alcance (nacional/internacional) o entidad, y revisa los resultados.
3. **Identificar convocatoria**: pega el texto (o la URL) de una convocatoria
   puntual para saber si es nacional o internacional y extraer su
   información clave.
4. **Administrar entidades**: agrega la URL de una nueva entidad financiadora
   y su frecuencia de actualización. Para agregar/editar/eliminar entidades o
   forzar una actualización inmediata, primero debes completar la
   "Configuración de GitHub" con un token de acceso personal (con permiso de
   escritura sobre este repositorio); el token se guarda solo en tu
   navegador. Buscar e identificar convocatorias no requieren ningún token.
