Pega la URL de una convocatoria puntual (o, si el sitio bloquea la descarga automática, pega directamente el texto de la convocatoria). El sistema indicará si es nacional o internacional y extraerá objetivo, fecha de cierre, monto y viabilidad para una universidad pública.

Agregar entidad financiadora

Solo se necesita la URL del listado de convocatorias de la entidad: el sistema intentará detectar automáticamente los ítems. Si conoces la estructura HTML del sitio, puedes afinar el resultado con selectores CSS opcionales (avanzado).
